# Sketchfab Public Downloader

**v1.0**

**Language / Язык:** [English](README.md) | **Русский**

Расширение Chrome (Manifest V3) для скачивания **публичных** 3D-моделей Sketchfab в **glTF (`.glb`) ZIP**. Без аккаунта Sketchfab, логина и API-токена.

Работает и для моделей **без** официальной кнопки Download.

Интерфейс: **русский** и **английский**. Светлая и тёмная темы.

Репозиторий: https://github.com/seryi882/sketchfab-downloader-extension

---

## Что умеет v1.0

| Возможность | Описание |
|---|---|
| Публичные модели | Меш и по желанию текстуры из публичного viewer |
| glTF на выходе | `.glb` с PBR-материалами (Blender: Файл → Импорт → glTF 2.0) |
| Текстуры | По желанию. По умолчанию выкл. Защищённые карты дескремблятся ключом `pk` из вьюера |
| Настройки | Текстуры, режим разработчика, тема, язык — вступают в силу после **Применить настройки** |
| Два одинаковых окна | Popup расширения и плавающая панель **⬇** на странице модели |
| Массовая загрузка | Отдельная страница со списком ссылок |
| Тяжёлые модели | Расшифровка / дескрембл / ZIP в offscreen-воркере (паки 2K–8K) |
| Режим разработчика | Подробный лог в UI; в архив кладётся `download-log.txt` |

## Установка (режим разработчика)

1. Скачайте исходники **v1.0** из [Releases](https://github.com/seryi882/sketchfab-downloader-extension/releases) или клонируйте:
   ```bash
   git clone https://github.com/seryi882/sketchfab-downloader-extension.git
   cd sketchfab-downloader-extension
   ```
2. Chrome → `chrome://extensions`
3. Включите **Режим разработчика**
4. **Загрузить распакованное** → выберите эту папку
5. После каждого Reload расширения **обновите страницу модели** (`Ctrl+F5`)

---

## Как скачать

1. Откройте страницу **публичной** модели Sketchfab.
2. Откройте **Настройки** (popup или панель ⬇).
3. Включите **Скачивать текстуры**, если нужны карты (выкл — быстрый ZIP только с мешем).
4. При желании включите **Режим разработчика** и выберите тему / язык.
5. Нажмите **Применить настройки** — должна появиться зелёная надпись **Настройки применены**.
6. Скачайте со вкладки **Скачать** или с панели ⬇.

| Где | Как |
|---|---|
| Кнопка **⬇** | Открывает панель → **Скачать glTF ZIP** |
| Окно расширения | **Скачать эту модель** |
| Массовая страница | Popup → **Массовая загрузка…** → вставьте ссылки → **Скачать все** |

Неприменённые тумблеры ничего не меняют. Скачивание использует последние **применённые** настройки.

В Blender: **Файл → Импорт → glTF 2.0** → откройте `.glb`. Нажмите **Z → Предпросмотр материала** (режим Solid прячет текстуры).

## Настройки

| Настройка | По умолчанию | Заметки |
|---|---|---|
| Скачивать текстуры | Выкл | Если вкл, имя ZIP заканчивается на `-textures` |
| Режим разработчика | Выкл | Подробный лог; в архив добавляется `download-log.txt` |
| Тема | Светлая | Светлая / Тёмная |
| Язык | Язык браузера (EN / RU) | Сохраняется вместе с остальными |

Изменения действуют только после **Применить настройки**.

## Содержимое ZIP

```text
ModelName-abcd1234.zip              # или ModelName-abcd1234-textures.zip
├── ModelName.glb                   # открывать в Blender
├── model.gltf + model.bin          # внешний glTF
├── textures/                       # только если текстуры включены
├── file.osgjs
├── model_file.bin
├── model_file_wireframe.bin        # если есть
├── README.txt                      # ссылка на проект
├── info.json
└── download-log.txt                # только при включённом режиме разработчика
```

Защищённые карты Sketchfab дескремблятся (PNG/JPEG, в том числе 4K/8K). Если карту не удалось декодировать, остаётся публичный файл CDN и запись в `MISSING_BLIT.txt`.

## Как это устроено

1. Читает публичную embed/viewer-страницу (UID, материалы, URL меша, `diter.b`).
2. Достаёт актуальный static-ключ из live JS Sketchfab.
3. Скачивает `.binz` и расшифровывает через WASM.
4. Если текстуры включены: забирает карты из публичного API и дескремблит те, у которых есть `pk`.
5. Конвертирует osgjs → glTF (ось Y-up, чтобы модель стояла в Blender).
6. Собирает ZIP в offscreen-документе (service worker не тянет паки 4K/8K RGBA).

## Требования

- Chrome / Chromium / Edge (Manifest V3)
- Доступ к sketchfab.com, media.sketchfab.com, static.sketchfab.com

## Права

| Право | Зачем |
|---|---|
| `downloads` | Сохранить ZIP |
| `storage` | Настройки (текстуры, тема, язык, режим разработчика) |
| `tabs` / `activeTab` | Связь со страницей модели |
| `offscreen` | Расшифровка, дескрембл и упаковка больших паков |
| Доступ к доменам Sketchfab | Публичные данные viewer и карты CDN |

## Конфиденциальность

- Нет аналитики и телеметрии
- Нет логина Sketchfab и API-токена
- Используются только публичные данные viewer / CDN
